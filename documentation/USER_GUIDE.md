## Getting Started

### Account Setup
1. **Sign Up**
   - Visit the RecruitIQ signup page
   - Enter your organization details
   - Create admin credentials

2. **Initial Configuration**
   - Set up your company profile
   - Configure email settings
   - Add team members with appropriate roles

### First Login
1. **Dashboard Tour**
   - Overview of key metrics
   - Quick access to common actions
   - Recent activity feed

2. **User Preferences**
   - Notification settings
   - Display preferences
   - Profile management

### Dashboard Overview

#### Main Navigation
- **Home**: Overview and key metrics
- **Candidates**: Manage candidate profiles
- **Jobs**: View and create job postings
- **Matching**: Find best-fit candidates
- **Analytics**: Reports and insights
- **Settings**: System configuration

## Core Features

### Resume Parsing

#### Uploading Resumes
1. **Single Upload**
   - Click "Upload Resume" button
   - Select file from your device
   - Automatic parsing begins

2. **Bulk Upload**
   - Navigate to Candidates > Bulk Upload
   - Drag and drop multiple files
   - Monitor progress in the upload queue

#### Parsing Results
- **Confidence Score**: Overall parsing quality
- **Review & Edit**: Manually correct any inaccuracies
- **Save**: Store in candidate database

### Candidate Management

#### Creating Profiles
1. **Manual Entry**
   - Click "Add Candidate"
   - Fill in details
   - Upload supporting documents

2. **From Resume**
   - Upload resume
   - Review parsed information
   - Save as new candidate

#### Candidate View
- **Profile**: Contact and personal details
- **Experience**: Work history
- **Education**: Academic background
- **Skills**: Verified and inferred skills
- **Activities**: Application history

### Job Postings

#### Creating a Job
1. **Basic Information**
   - Job title and department
   - Location and work type
   - Salary range

2. **Requirements**
   - Required skills
   - Experience level
   - Education requirements

3. **Description**
   - Job responsibilities
   - Company culture
   - Benefits

### Matching Engine

#### Finding Candidates
1. **Quick Match**
   - Select a job posting
   - View top matches
   - Filter by score or criteria

2. **Advanced Search**
   - Multiple search criteria
   - Boolean operators
   - Save search queries

#### Match Details
- **Fit Score**: Overall match percentage
- **Skills Match**: Required vs. candidate skills
- **Experience**: Years and relevance
- **Education**: Degree and institution match

### AI Assistant

#### Getting Recommendations
1. **Ask Questions**
   - Natural language queries
   - Context-aware responses
   - Follow-up questions

2. **Smart Suggestions**
   - Interview questions
   - Candidate comparisons
   - Market insights
